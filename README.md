# 极氪 007GT 焕新版购车决策报告

一个基于 React、Vite 和 Tailwind CSS 的单页购车决策网站，围绕极氪 007GT 焕新版、小米 SU7 Max、特斯拉 Model 3 做技术科普、横向对比和试驾行动清单。

## 本地运行

```bash
pnpm install
pnpm run dev
```

## 构建

```bash
pnpm run build
```

## 内容说明

- 设计系统来自 `UI-decision.md`
- 信息架构来自 `IA.md`
- 页面入口在 `src/pages`
- 车辆图片来自 Wikimedia Commons，见页脚授权说明

## GitHub Pages

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
